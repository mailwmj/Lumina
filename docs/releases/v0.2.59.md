## 新增

- 画布右侧新增内置 Agent 面板：通过对话理解需求、澄清问题、撰写提示词，并调用现有生图节点出图和反复修改；默认每次生成 1 张，明确指定张数时按指定生成。
- Agent 面板支持多会话（重命名、删除）、按会话保留草稿和模型选择，可拖宽、可收起；支持上传、粘贴、拖入图片，以及用 @ 引用画布图片。
- 画布节点工具条新增“加入对话”“查看对话”。
- 设置页新增 Agent 分组；不支持工具调用的模型在选择时置灰。
- 会话随项目持久化，删除项目时一并清理。

## 修复

- 修复 `@tauri-apps/api` 与 `@tauri-apps/plugin-http` 版本高于 Rust 端对应 crate，导致 Tauri 打包因版本不匹配失败（v0.2.58 未能发布）。
